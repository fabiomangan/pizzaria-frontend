# 🍕 Pizzaria Frontend

Frontend da aplicação **Pizzaria**, desenvolvido com stack moderna focada em performance, escalabilidade e boas práticas de organização de código.
O projeto consome uma API REST e simula o fluxo real de um sistema de pedidos de pizzaria.

---

## 🚀 Tecnologias Utilizadas

* **Next.js** (App Router)
* **TypeScript**
* **React**
* **Tailwind CSS**
* **shadcn/ui**
* **Git** (versionamento com commits semânticos)

---

## 🎯 Funcionalidades

* Listagem de produtos (pizzas)
* Interface responsiva
* Componentização reutilizável
* Estrutura preparada para integração com backend REST
* Layout moderno e acessível

---

## 📂 Estrutura do Projeto

```bash
src/
├── actions         # Autenticação de usuários
├── app/            # Rotas e páginas (Next.js App Router)
├── components/     # Componentes reutilizáveis
├── lib/            # Utilitários e helpers
```

Estrutura organizada visando **manutenibilidade**, **escala** e **clareza de responsabilidades**.

---

## ▶️ Como rodar o projeto localmente

### Pré-requisitos

* Node.js (versão 18+ recomendada)
* NPM ou Yarn

### Passos

```bash
git clone https://github.com/fabiomangan/pizzaria-frontend.git
cd pizzaria-frontend
npm install
npm run dev
```

O projeto ficará disponível em:

```
http://localhost:3000
```
